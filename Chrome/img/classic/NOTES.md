# Dialup Classic icons

Original pixel artwork for the Classic skin. Transparent SVGs use only axis-aligned integer rectangles, `shape-rendering="crispEdges"`, and the specified classic palette (plus #d4d0c8). Highlights come from the top-left; there are no gradients, filters, text, logos, or external assets.

24×24 toolbar icons:
- `back.svg` — green left arrow
- `forward.svg` — green right arrow
- `stop.svg` — document with red X
- `reload.svg` — document with two green return arrows
- `home.svg` — house
- `favorites.svg` — yellow star
- `wayback.svg` — clock with green back arrow
- `dialup.svg` — beige CRT with blue screen
- `go.svg` — green square with right arrow

16×16 status and tab icons:
- `page.svg` — document with blue globe
- `page-sm.svg` — simplified document and globe
- `lock.svg` — padlock
- `sound.svg` — speaker with sound waves
- `sound-off.svg` — speaker with red X
- `zone.svg` — globe

`throbber.svg` is a static globe centered in a 22×22 cell.

`preview.png` shows every SVG rasterized at 4×, alongside its native-size rendering, on #d4d0c8. Use integer display sizes and nearest-neighbor scaling to preserve the pixel grid.
